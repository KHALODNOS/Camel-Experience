# Agadir Camel Experience

An adventure booking website concept for discovering camel rides, horse riding, coastal sunsets, and day trips around Agadir, Morocco. The design pairs warm Moroccan colors and editorial typography with clear activity details and booking calls to action.

## What the website offers

- Camel sunset treks and camel rides with Moroccan tagine dinner
- Arabian horse riding and horse riding with dinner
- Quad dune safaris, Paradise Valley excursions, and Souss Valley tours
- A quick booking panel for choosing an adventure, date, and number of travelers
- Activity discovery, tour information, a photo gallery, about, and contact sections
- Prominent booking and phone contact links

Featured experiences include two-hour camel and horse rides, with sample prices shown from €10 per person and dinner options from €15. Availability and final pricing should be confirmed when booking.

## Project files

- `src/` contains the React and Vite application.
- `public/stitch_agadir_camel_experience_showcase/` contains the website showcase HTML and its design notes.

## Run locally

Install dependencies and start the development server:

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

The app is built with React 19 and Vite 8.
